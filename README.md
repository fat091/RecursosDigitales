# RecursosDigitales

Aplicación móvil desarrollada como proyecto académico para la gestión y consulta de recursos digitales.

## Descripción

RecursosDigitales es una aplicación Android desarrollada para facilitar la organización, la administración y el acceso a recursos digitales desde un dispositivo móvil.

El proyecto forma parte de mi formación en Ingeniería en Ciencias de la Computación y me permite aplicar conocimientos de desarrollo de aplicaciones móviles, programación en Java y diseño de interfaces.

## Funcionalidades

- Gestión de recursos digitales.
- Consulta y organización de información.
- Navegación mediante una interfaz móvil.
- Administración de información desde la aplicación.

## Tecnologías utilizadas

- Java
- Android Studio
- Gradle
- Git
- GitHub

## Estado del proyecto

En desarrollo.

Actualmente se continúa trabajando en la implementación y mejora de las funcionalidades de la aplicación.

Este proyecto fue desarrollado como parte de mi formación universitaria en Ingeniería en Ciencias de la Computación en la Benemérita Universidad Autónoma de Puebla (BUAP).

Su desarrollo busca aplicar conceptos de programación, diseño de aplicaciones móviles y gestión de información en un proyecto práctico.
